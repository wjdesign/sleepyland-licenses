# Sleepyland Licenses

Sleepyland 哄睡音效 App 的法務與支援頁面，透過 GitHub Pages 對外提供。

## 頁面

| 頁面 | 檔案 | 網址 |
|------|------|------|
| 主頁 | `index.html` | https://wjdesign.github.io/sleepyland-licenses/ |
| 隱私政策（繁中） | `privacy.html` | https://wjdesign.github.io/sleepyland-licenses/privacy.html |
| Privacy Policy (EN) | `privacy-en.html` | https://wjdesign.github.io/sleepyland-licenses/privacy-en.html |
| 使用條款（繁中） | `terms.html` | https://wjdesign.github.io/sleepyland-licenses/terms.html |
| Terms of Service (EN) | `terms-en.html` | https://wjdesign.github.io/sleepyland-licenses/terms-en.html |
| 支援中心 | `support.html` | https://wjdesign.github.io/sleepyland-licenses/support.html |

## 其他檔案

- `config.json` — App 遠端開關設定檔（feedback_enabled / rate_enabled，App 啟動時讀取）

## 維護說明

- 所有頁面為單檔 HTML（CSS 內嵌），主色 `#5B6ABF` 夜藍紫
- 修改內容直接編輯對應 HTML，push 到 `main` 後 GitHub Pages 自動更新（約 1~2 分鐘）
- 隱私政策/使用條款有變更時，記得同步更新繁中與英文兩版，並更新頁面內的「最後更新」日期
- 聯絡信箱出現在多個檔案中，更換時需全域搜尋替換
